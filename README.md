# OXCART Transfer Arm Control

Arduino-based control project for the **OXCART buffer chamber transfer arm**.

This repository contains the hardware-control logic and supporting materials for operating a transfer arm used in a laboratory vacuum or buffer-chamber environment.

---

## Overview

The project focuses on controlling the motion and operation of a transfer-arm subsystem used in the OXCART setup.

A circuit diagram is included in the repository to document the wiring and hardware connections.

---

## Features

- Arduino-based control logic
- Laboratory hardware integration
- Transfer-arm control for buffer chamber operation
- Supporting circuit documentation

---

## Repository Contents

- control code for the transfer arm
- hardware connection information
- circuit diagram for the setup

---

## Intended Use

This project is intended for experimental and laboratory hardware environments OXCART APT where a transfer arm must be controlled through a lightweight microcontroller-based system.
